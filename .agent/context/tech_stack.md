Verified and required versions for the repository.

- **Runtime**: .NET 10.0.3 (Preview/Stable as available)
- **Language**: C# 14

- **Framework**: ASP.NET Core MVC & Blazor

- **Documentation**: C#-XML Documentation (`/// <summary>`)
